# 🌐 Personal Portfolio Website

A responsive and modern personal portfolio website built using HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive design for various devices
- Interactive navigation menu
- Showcase of projects and skills
- Contact form integration

## 📸 Live Demo

[View Live Website](https://skydreamerrr.github.io/Project-3_Portfolio-Website/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📥 Getting Started

To view the website locally:

1. Clone the repository:
   git clone https://github.com/SKYDREAMERRR/Project-3_Portfolio-Website.git
   
3. Navigate to the project directory:
   cd Project-3_Portfolio-Website
   
5. Open index.html in your preferred web browser.
